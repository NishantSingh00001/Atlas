# Included asset credits

- `textures/earth-topography-8192.jpg` and `textures/earth-topography-4096.jpg`: optimized JPEG derivatives of NASA Blue Marble: Next Generation, January base map with topography and bathymetry (source: 21600 × 10800 JPEG). Atlas selects the 8192-pixel map on capable GPUs and falls back to 4096 pixels on older hardware. NASA describes the source as a shaded topographic and bathymetric map. NASA source page: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/
- `vendor/three.min.js`: Three.js r128. See `vendor/THREE-LICENSE.txt` for the MIT license text.
- Destination photographs are fetched at runtime from Wikimedia Commons. Their file page, contributor, and license are linked in the on-page caption; the photos are not included in this zip.
- `atlas-earth-horizon.png` is generated editorial artwork bundled as a generic fallback when no destination photo can be loaded. It is illustrative scenery, not live satellite imagery or a real destination photograph.
- `kyoto-kiyomizu-editorial.png` is generated illustrative artwork based on Kiyomizu-dera in Kyoto. It is labeled as illustrative and is not a real photograph. A credited Wikimedia Commons photo replaces it when that service is available.
